# Synthetic Obsidian — third-party notices

This first-test build includes third-party software and model files required
for local audio analysis, backing-note generation, and voice conversion.

The distribution includes or uses:

- JUCE 8
- Python 3 and its standard library
- PyTorch and torchaudio
- MLX
- NumPy, SciPy, librosa, soundfile, and related Python packages
- SoulX-Singer
- Synthetic Obsidian backing-vocal model weights

The corresponding copyright notices and license terms remain applicable.
The SoulX-Singer source tree included in the application contains its
upstream `LICENSE` file. Python packages retain package metadata and license
files collected by the frozen-worker build where supplied upstream.

with individual components.
