# Synthetic Obsidian — Документация проекта

**Synthetic Obsidian** — это VST3/ARA2 плагин с интегрированными AI/ML функциями для профессиональной обработки вокала. Система использует технологию голосового преобразования (RVC) для создания синтетических вокальных трактов, сохраняя естественность и выразительность оригинального исполнения. Плагин предназначен для студий звукозаписи, продюсеров и музыкантов, работающих в DAW (Digital Audio Workstation).

## Ключевые технические решения

### Технический стек
- **Фреймворк:** JUCE 8 (кросс-платформенная разработка аудио плагинов)
- **Стандарты плагина:** VST3 (первая фаза), ARA2 (вторая фаза)
- **Хост-совместимость:** macOS (Intel + Apple Silicon), Windows (x86-64)
- **Опционально:** Linux поддержка

### AI/ML компонент
- **Model:** RVC v2/v3 (Retrieval-based Voice Conversion)
- **Лицензия:** AGPL-3.0 (требует уточнения с заказчиком для коммерческого использования)
- **Альтернативы:** коммерческие модели voice conversion (если AGPL недопустима)
- **Inference engine:** ONNX Runtime (кросс-платформенная поддержка)

### Интеграция Python-C++
- **Bridge:** pybind11 для вызова Python кода из C++
- **Возможно:** встраивание Python runtime или выделенный процесс для ML inference

### Фазы разработки
1. **Фаза 1 (MVP):** Standalone приложение + базовый VST3
2. **Фаза 2:** ARA2 интеграция (расширенные возможности в совместимых DAW)
3. **Фаза 3:** Оптимизация, additional features, расширенная платформоподдержка
